# Passport Cropper

A simple web-based passport photo cropping tool.

Upload an image, select a passport photo size, adjust the crop, and download the finished photo.

[**🌐 Open Passport Cropper**](https://StringOfLogic.github.io/PassportCropper/)

## Features

* Upload JPG, PNG, and WebP images
* Select passport photo sizes
* Interactive image cropping
* Download cropped photos
* Light / dark mode
* Responsive design

## Built With

* React
* TypeScript
* Vite
* Tailwind CSS
* React Image Crop
